How this works

About

Generates a two-color, 3D-printable patch in the common hook-and-loop (Velcro / "morale patch") sizes from any image or a line of text. The patch is a flat base plate in one color with the artwork raised on top in a second color, so it prints without supports and gives a crisp two-tone look with a single color change.

How to use

  • Pick a size preset (3″×2″ morale patch, 3.5″×2″ flag, rounds, name tapes, shield…) or type custom dimensions.
  • Drop, choose, or paste (Ctrl/⌘+V) an image — or switch to Text for name tapes and callsigns.
  • Choose what gets raised: dark areas, light areas, or everything non-transparent (best for logos with transparent backgrounds). Tune the threshold, smoothing and speck removal until the preview looks clean.
  • Optionally add a raised border, then export.
  • 3MF (2 parts) loads into Bambu Studio / OrcaSlicer / PrusaSlicer as one object with two parts — assign a filament to each. Or export the STLs separately.
  • Single-extruder printers: export the combined STL and add a filament change (M600 / pause) at the Z height shown under the preview.

Attaching: stick or glue adhesive-backed hook tape to the flat back (the loop side lives on bags, caps and plate carriers). A textured PEI plate gives the front-facing base a nice finish if you flip the model face-down — but then the color change goes at the base thickness from the bottom, which is what the default orientation already gives you.

Technical details

The patch outline is built as a polygon (rounded rectangle, ellipse, shield or hexagon) and the base is a straight extrusion of it, triangulated as a fan since every shape is convex. The artwork is rasterised onto a grid at the chosen resolution with a canvas (ctx.filter = blur() for smoothing), thresholded, clipped using a signed-distance field of the outline, and cleaned with a connected-component pass that removes small islands and fills small holes.

The raised layer is meshed directly from the grid: top/bottom faces are merged into per-row runs, and side walls are emitted only where an "on" cell meets an "off" one. Each run's edges get extra vertices wherever the neighbouring row changes, and it is triangulated as a zipper strip between them, so the mesh has no T-junctions. Cells that touch only at a corner are bridged, so the exported mesh is watertight and manifold with no slicer repair needed. Exports are written in-browser: binary STL via DataView, and 3MF as a hand-built uncompressed ZIP (with CRC-32) containing a model with two mesh objects joined as components. No libraries, nothing uploaded.
