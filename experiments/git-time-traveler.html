How this works

About

Git Time Traveler teaches git to a non-technical person by leaning on one metaphor that happens to be technically accurate: git is a time machine with parallel timelines. You build a little pixel world (the "working directory"), place the parts you want to keep on the Staging Altar, and stamp a Save Point (a commit). The growing pixel timeline graph is the real commit history.

How to use

Pick a level. Read the quest, then change the world with the World Editor buttons, Stage what you want to keep, and create a Save Point. Across 3 worlds (10 levels) you unlock branches (parallel timelines), merging and conflict resolution, and finally the collaborative loop — a remote "Cloud Mirror" you push, fetch and pull with a teammate. From World 2 on, a real-command terminal unlocks so you can graduate from buttons to typing actual git commands. Every action also prints the equivalent real command into the Command Log. Progress and stars are saved in your browser.

Technical details

A small but faithful in-memory git engine (commits with parent links, branches, HEAD, working tree, staging index, fast-forward + 3-way merge with conflict detection via a common-ancestor diff, plus a second commit store standing in for a remote with origin/* tracking refs and push/fetch/pull) drives the whole game; level objectives are validated against the real engine state, not scripted. Everything renders to two <canvas> elements with hand-drawn pixel art. Pure vanilla HTML/CSS/JS, no imports, single file.
